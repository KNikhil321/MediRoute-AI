About MediRoute AI

Framework for Intelligent Report Routing and Physician Assignment in Healthcare

Project Overview

MediRoute AI is an administrative healthcare report-routing research prototype developed for an M.Tech project demonstration. It supports department classification, predefined emergency-indicator screening, and availability-conscious physician assignment using simple local text-processing techniques.

The system is designed to illustrate how keyword-based NLP and load-balancing heuristics can assist hospital administrative workflows. It is not a clinical decision-support system and must never be used with real patient data in a production clinical setting.

Key Capabilities
  • Weighted keyword matching for department prediction (Cardiology, Neurology, Dermatology, Orthopedics, General Medicine, Pediatrics, Gynecology, Other)
  • Emergency-indicator screening using a fixed list of high-priority phrases
  • Least-pending-load physician assignment among available doctors of the predicted department
  • Full audit trail of every routing and management action
  • Persistent SQLite storage – works offline and on free hosting platforms
Technical Approach
  • Frontend: HTML + CSS + Bootstrap 5 + vanilla JavaScript
  • Backend: Python Flask
  • Database: SQLite (zero-configuration)
  • NLP: Pure Python weighted keyword scoring (no external LLM APIs)
Disclaimer

This system does not diagnose diseases, replace doctors or provide emergency medical care. All demonstration records are synthetic. Emergency screening is basic keyword matching only and is not a substitute for clinical triage. In a real emergency call 112 (India) or your local emergency number.
